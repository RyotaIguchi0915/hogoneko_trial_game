# L0 — Data 定義層

**責務**: 全定義データ（猫プロファイル / 家具 / アイテム / 部屋 / イベント / 現象語彙 / シナリオ）の読込・スキーマ検証・提供。ロジックを持たない。

**依存**: なし（葉ノード）。**誰も参照しない・参照されるのみ**（B4 DR-8）。

**禁止**: 実行時の定義書き換え / ロジックの混入 / 未検証定義の提供。

**参照 Bible**: B4 D-01・D-02 / B0 §14.2

**担当 Epic**: EP-09 Data Layer Foundation

> ⚠️ ID命名規則・JSON具体形式は B11（未作成 / OI-2）確定後に実装する。
