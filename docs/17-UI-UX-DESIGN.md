# B?: UI/UX Design — 「やさしい観察画」（OI-4）

Status: **方向確定（AI 提案 → 人間確定・2026-07 承認）**。実装は段階導入。本番アート（猫の絵）・結末の中身・ダーク対応・レイアウト精緻化は監修/後続。

保護猫トライアル30日の画面設計方針。プレイヤーは操作するのではなく **見て、待って、気づいて、ときどき吹き出す**。UI はその時間を、**まるく・あたたかく・静か**に包む。

> 叩き台モック（トーンの正）: Artifact「やさしい観察画」v3。実装は本ドキュメントを正とする。

## 1. 原則（やさしくても、ぶれない）

1. **しずけさ**（Pillar 6）— 達成演出・焦燥演出を持たない。進捗バー・ポップアップなし。時間はやわらかく流れる。
2. **数字は見せない**（観測境界・憲章 I-1）— 警戒度も好感度も出さない。受け取るのは「見えたこと」の言葉だけ。数値は Player 側（観測回数など）に限り、Cat State（内部状態）は決して出さない。
3. **構図はそのまま**（B3 ③）— 同じ窓から同じ部屋を見る。動くのは中の猫と、それを言い表す言葉だけ。
4. **そっと、少しだけ**（B2 §4・憲章 I-2）— 観察は無制限、介入は行動枠のぶんだけ。できることは静かに、少なく。

## 2. トーン: ポップで、優しくて、ちょっと可笑しい

- **ユーモアは演出で足さず、猫にまかせる。** 正直に観るほど猫はおかしい（寝姿はまるく食パンのよう、犯行現場ではしれっと真顔、食器の前ではやたら真剣）。
- したがって **観察文は factual のまま**（「見えたこと」だけ・解釈しない）。可笑しさは **行動→ポーズ**（EP-2.02 実装済）と絵・間（ま）が担う。文でボケない。
- 切なさ（痕跡）・かわいさ（寝姿）・可笑しさ（犯行現場）の三拍子でトーンに幅を持たせる。

## 3. 設計トークン

### 色（ライト・温かいクリーム＋ハチミツの差し色＋添えのセージ）
| token | 値 | 用途 |
|---|---|---|
| ground | `#f7efe0` | 下地 |
| surface | `#fffdf7` | カード |
| surface-2 | `#f4ecdd` | 副次面・非活性ボタン |
| ink / ink-2 / ink-3 | `#5d4c3f` / `#93806e` / `#bcab97` | 文字（濃→淡） |
| hair | `#ecdfc9` | 罫・境界 |
| **honey** | `#e79a4d` | **唯一の主役色＝「今できる操作」**（ご飯をあげる・次へ進む・決める） |
| sage / sage-soft | `#86ac93` / `#e2ecdf` | 添え色＝「気づき」（観察ノート） |
| blush | `#f0b39c` | 猫のほお・ちいさな温かみ |
| cat | `#c2a488` | 猫（プレースホルダ描画時） |

⚠️ **ダークテーマ**は方針あり（温かい夜の部屋）だが未実装（App は現状ライト固定・inline style のため）。CSS 化とあわせて後続で対応。

### 書体
- **丸ゴシック**（`Hiragino Maru Gothic ProN` → `Rounded Mplus 1c` → `Hiragino Sans`/`Yu Gothic UI` フォールバック）。観察の言葉も操作も、ひとつのやさしい声で。
- CSP/容量のため日本語 Web フォントは埋め込まない（システム丸ゴシック依存）。丸みは形（角丸・丸薬ボタン）でも担保する。

### かたち・間
- 大きな角丸（カード 24px・シーン窓 20px・**ボタンは丸薬型 999px**）、やわらかい影、広い余白、行間 1.75。角のない世界。焦らせない。
- 構図は中央固定・カード幅 ~26rem。

## 4. 画面インベントリ

- **本編・在室**: まるい窓に猫 → 観察文（1行・大きめ）→ 進行（N日目・n/6）→ 操作（ご飯をあげる〈honey・枠数〉/ 次へ）→ 観察ノート（sage カード）。
- **本編・不在**: 「姿が見当たらない」＋痕跡（副文）。介入は枠 0 でやさしく無効化。
- **本編・犯行現場（ユーモア）**: 「物の位置が変わっている」＋構図の中の“何も知らない顔”。文は淡々と。
- **結末アーク**: deciding →〈決める〉→ ending →〈つづける〉→ epilogue →〈つづける〉→ reflection（終端・操作なし）。同じ器・同じやわらかさで語りへ。
