## 0. なぜこの文書か

デモをプレイした結果、**「ただボタンを押すだけのゲーム」**になっているという根本的な指摘を受けた。
本来の目的（憲章 `docs/00:101` 「**プレイヤーが猫を理解すること**」）に対して、現状は理解が起きる余地が無い。

原因はコードの調査で確定している（＝機能の欠落であって、設計思想の誤りではない）:

| # | 欠落 | 根拠（現状実装） | 本来（バイブル） |
|---|---|---|---|
| 1 | **猫が毎回“同じ個体”** | `initialCatState()` は毎回同一定数。`profile` 乱数ストリームは宣言のみで未使用。CatState に隠れ特性が無い | 8軸の気質で個体が定義され seed 生成・プレイ中不変（`docs/04:1877-1892` / `docs/05:815-844`） |
| 2 | **手が「ごはん」1つだけ** | `GameRuntime.feed()` のみ。環境はプレイヤーが変えられない（家具設置未実装・居場所は猫が選ぶ・変化は自動イベントのみ） | 環境＝猫に語る唯一の言語。家具/人の距離/資源配置/隠れ家で Zone 属性を変える（`docs/09` / `docs/10:554`） |
| 3 | **観察に文脈が無い** | descriptor→結論文が出るだけ。刺激（音）は観察に出ず、引き金・時間・場所が見えない | 観察は複層（猫/痕跡/環境/時間帯/音）。全事象は観測可能な Cue を直接＋間接で持つ（`docs/01:146` / `docs/07:822`） |
| 4 | **仮説・理解の仕組みが無い** | Player Knowledge は「何を・何回・いつ見たか」の集計のみ | 理解の8段階 U0〜U7、仮説システム、確信度×スコープ、誤解設計（`docs/06`） |
| 5 | **結末が隠れ絆メーター** | trust 閾値で bondTier を出し分け（EP-3.08） | 3つの等価な結末が**プレイヤーの理解の到達点を映す鏡**（`docs/00:460-472` / `docs/01:369`） |

> 骨格（観察する・待つ・そっと世話する・去就を決める）は正しい。抜けているのは
> **「個体・文脈・仮説・働きかけ・答え合わせ」**の5つ。これらを戻すのが本計画。

## 1. 目指すコアループ

バイブルの定義（`docs/00:1065` / `docs/13`）そのまま:

```
観察 → 仮説 → 働きかけ → 反応（答え合わせ）→ 理解 → 観察…
```

- **観察**: いつ・どこで・何のあとに、どう振る舞ったか（文脈つき）。
- **仮説**: 「この子は音が苦手そう」「高い所で落ち着く」——観察から**推し量って持つ**（採点しない・`docs/06:616`）。
- **働きかけ**: 環境と自分の距離を整える（隠れ家を置く／ごはんを静かな隅へ／距離をとる）。**猫は操作しない**（I-2）。
- **反応**: 猫が自律的に反応する。仮説に沿った環境なら落ち着き、外れれば変わらない。
- **理解**: 仮説を直す。「この子は、こういうときこうなる」が育つ。
- **結末**: 「この子をどれだけ分かったか／この子に合う家はどこか」で去就を決める（3結末は等価・I-9）。

## 2. 再構築の5ブロック（依存順）

各ブロック: **狙い / バイブル根拠 / MVP で作る最小形 / データと層 / 監修が要る所**。
MVP は「毎回違う猫を、文脈から読み、環境で応え、理解が結末に映る」一周が**成立する最小**に絞る。8軸/24タイプ/U0-U7 の全面実装は後続。

### B-A 個体（CatProfile）— これが全ての土台

- **狙い**: 「理解する相手＝その子」を存在させる。個体差は難易度差ではなく**違う個体**（`docs/04:1934`）。
- **根拠**: `docs/04:1863-1919`（§9 個体差モデル）、`docs/05:774-844`（性格＝8次元空間の点・24タイプ）。
- **MVP 最小形**: 8軸すべてでなく、**観察で読めて／仮説にでき／環境で応えられる4軸**に絞って効かせる:
  - **T-1 神経質さ**（刺激への反応の強さ）→ Vigilance 感度・突発音反応。
  - **T-7 遮蔽選好**（開放↔隠れ好み）→ Zone の cover 重み。
  - **T-6 高所選好**（床↔高所）→ Zone の height 重み。
  - **T-2 社会性**（単独↔人を求める）→ 人の距離への反応・familiarity/trust の育ち。
  - 残り4軸（活動/探索/順応/回復）は MVP では中立既定に固定（後続で開く）。
- **データと層**:
  - `CatProfile { temperament: {neuroticism, cover, height, sociability, ...}, decisionTemperature, ... }`（L1 core の型）。
  - **seed から決定論生成**（`RNG.stream('profile')` を実配線）。少数のベース定義＋微小変動（完全ランダムにしない・`docs/04:1910`）。
  - **プレイ中不変**。CatState とは分離（CatState=可変の状態、CatProfile=不変の素性）。
  - **保存不要**: profile は `f(seed)` なので復元時に seed から再生成でき、save schema を増やさない。
  - **L4 に数値・タイプ名を絶対に出さない**（I-1 / `docs/05:777`）。sim 内部だけで効かせる。
- **監修**: 4軸の実値レンジ、MVP 用のベース個体セット（例 3〜5個体＝「慎重観察型」等 `docs/05:815`）。

### B-B 文脈つき観察 — 推論の材料をつくる

- **狙い**: 「なぜその行動をしたか」をプレイヤーが**相関させられる**ようにする。
- **根拠**: `docs/01:146`（観察は複層：猫/痕跡/環境/時間帯/音）、`docs/07:822`（全事象は直接＋間接 Cue を持つ）、`docs/07:541-660`（トリガー体系）。
- **MVP 最小形**:
  - **刺激（音）を観察に出す**: 現状 stimulus は Vigilance を上げるだけで不可視。`phenomenon.sudden_noise`（例「物音がした」）を Phenomenon として越境させる。
  - **場所を観察に添える**: 猫の currentZone を観察文の文脈に（例「本棚の上でじっとしている」）。Zone は既に存在（EP-3.02）。
  - **時間帯を文脈に**: Segment（朝/昼/夕/夜）を観察の並びに添える（既に day/segment は L4 にある）。
  - → 観察が「**〈時間帯〉、〈場所〉で、〈引き金〉のあと、〈行動〉**」の形に読める。
- **データと層**: L3 Perception の `toPhenomena` を拡張し、行動 descriptor に加えて**刺激・場所の Phenomenon** を返す。数値は載せない（`Phenomenon` の数値禁止ガードは不変）。語彙は content/locales に追加。
- **監修**: 追加現象語彙（音・場所・時間帯の「見えた事実」表現）。承認済み最小セットの拡張（`docs/07` EC の Cue に整合）。

### B-C 仮説と理解 — 観察ノートを「推論の場」にする

- **狙い**: プレイヤーが**能動的に推し量る**行為を loop の中心に据える。「反復＋対比＝仮説」（`docs/06:126`）。
- **根拠**: `docs/06:215-310`（理解8段階 U0-U7・Insight・確信度×スコープ）、`docs/06:614-701`（仮説システム）、`docs/06:1176`（誤解設計）。
- **MVP 最小形**:
  - 観察ノート（EP-2.07）を**仮説帳**に進化。B-A の4軸に対応する少数の仮説テンプレを、**観察した現象からのみ**選べる（`docs/06:660` 観測していないものは材料にならない）:
    - 「この子は物音が苦手そう」／「高い所で落ち着くみたい」／「隠れられる場所を好む」／「そばに来てくれる ／ まだ距離がある」／「朝（夜）に活発」。
  - **唯一の支援＝描写解像度**（`docs/06:681-701`）: 仮説を持つと、その仮説に関連する現象の観察文が**詳しくなる**。**正誤は示さない**（間違った仮説でも詳しくなる）。
  - 確信度・理解段階は**内部保持のみ**、**数値表示しない**（描写の解像度に反映・`docs/06:363`）。
  - 対比観測（起きた／起きなかった）で気づきが仮説に上がる。反証が来たら**責めずに**解像度を戻す（`docs/06:1291`）。
- **データと層**: L3 Player Knowledge に Insight（`docs/06:266` の最小版：observationCount/contrastObserved/hypothesisFormed/confidence/scope）。**真実は参照しない**（G-2・`docs/06:26`）。プレイヤーが選んだ仮説は**プレイヤー入力なので保存が要る**（観察履歴から導出できない）→ save schema v4 に「選択済み仮説」を追加。
- **監修**: 仮説テンプレの文言・語調（推量形）、描写解像度の「詳しい版」観察文。

### B-D 環境アクション — 猫に語りかける言語

- **狙い**: 理解を**行為に変換**する手段。ただし猫は操作しない（I-2）。「環境＝猫に語る唯一の言語」（`docs/10:554`）。
- **根拠**: `docs/09`（家具は効果を持たず Zone 属性に寄与・`:565`／`:462-494` レバー関係図）、`docs/09:318`（段ボール＝退避 Zone を1つ生成）。
- **MVP 最小形**（4アクション程度）:
  - **隠れ家を置く**（段ボール）→ cover の高い退避 Zone を生成。
  - **高い場所を作る**（棚）→ height の高い Zone を生成。
  - **ごはんを静かな隅へ**（資源配置）→ 食事 Zone を人の動線から離す。
  - **自分の距離をとる／近づく**（人の位置）→ humanDistance を変える。**近づいても猫が来る保証はない**（I-2）。
  - 効果は**個体依存**（同じ棚が、高所選好の高い子には効き、低い子には無意味）。→ ここで B-A が効く。
- **データと層**: L2 Simulation に環境操作（Zone 生成／属性変更／資源配置／human 位置）。合成ルート（`src/app`）が Command として受け、猫は次 Segment で自律反応。**保存が要る**（設置済み家具・ごはん位置・人の距離）→ save schema v4。
- **監修**: 各アクションが Zone 属性に与える寄与値、家具の初期セット（`docs/09:580-664` カテゴリ）。

### B-E 理解を映す結末 — 絆メーターの廃止

- **狙い**: 結末を「懐き度」でなく**プレイヤーの理解の到達点の鏡**にする（`docs/01:369` / `docs/00:388`）。
- **根拠**: `docs/00:460-472`（3結末を用意し優劣をつけない）、I-9（見送りを失敗として演出しない・`docs/00:77`）。
- **MVP 最小形**:
  - **現行の bondTier（trust 閾値 0.25/0.55 の出し分け・EP-3.08）を廃止/置換**。
  - 去就は3択に：**正式に迎える／トライアルを延ばす／送り出す**（`docs/00:463-471`）。**どれも失敗ではない**。
  - 結末の語りは、**プレイヤーがどれだけこの子を見て・推し量ったか**（Insight の充足＝立てて確かめた仮説の広がり）と、**環境がこの子に合っていたか**（profile と設置環境の適合）を映す。数値は出さない（質的な語り）。
  - ⚠️ 「理解度」を厳密に測る U0-U7 の全実装は後続。MVP は**証拠構造の代理指標**（立てた仮説数×対比観測の有無＋環境適合）で語りを分岐する軽量版。
- **監修**: 3結末×語りの本文、代理指標の閾値。

## 3. 憲章・境界の順守（不変）

- **I-1（数値を L4 に出さない）**: CatProfile・confidence・理解段階はすべて sim/L3 内部に留め、L4 には質的な語り（Phenomenon 由来の文字列・描写解像度）だけを渡す。`Phenomenon` の数値禁止コンパイルガードは不変。
- **I-2（猫を命令で動かせない）**: 環境アクションは「働きかけ」であって命令ではない。**猫が応じる保証を UI で示唆しない**。
- **G-2（Player Knowledge は真実を参照しない）**: 仮説・理解は観察履歴からのみ構築。正解照合をしない。
- **G-3（決定論）**: profile は seed 生成、環境反応は既存の用途別 RNG stream で。`Math.random`/`Date` 禁止は不変。
- **保存**: CatProfile は再生成で schema 不要。**仮説・設置環境・人の距離**は保存が要る → **save schema v4＋マイグレーション**（v3→v4、既存セーブは空既定で補完）。
